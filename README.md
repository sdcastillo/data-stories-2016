# data-stories-2016
Course materials and website for Telling Stories with Data (PUBHLTH 490ST) in Spring 2016 at UMass-Amherst.

Live site (GitHub Pages, default branch root): https://sdcastillo.github.io/data-stories-2016/

The notes page is `pages/insights.md`: five arguments taken from the lectures and labs (Simpson’s paradox on the SAT, the iPod shuffle, the visualization principles, permutation tests, and missing data on the Titanic).

Listed on [SamWiki](https://sdcastillo.github.io/samwiki/).
